## 已知边界

- **服务端会话删除**：当前 DSH Remote API 没有 `session/delete`/`session/remove` 端点；网页端只有归档。App 已提供“本机列表删除 + 归档恢复”，无法删除服务器上的会话文件。
- **逐字流视觉**：WebSocket 帧已验证，但真实模型的 reasoning 阶段较长，界面显示 thinking；尚未截到正文逐字增长画面。
- **完整 i18n**：主要页面/导航已英文化；日志、部分错误提示和插件文案仍为中文。
- **SSH / DSRemote**：需要独立连接层与主机密钥管理，未实现。
- **完整插件运行时**：已支持 `plugin/card` 与 `actions` 结果卡；完整清单/表单/面板协议未实现。
- **远端推送**：GitHub 与 Gitee 已同步到 `c0997c3`，并推送 `v0.42.0`–`v0.47.0` 标签；Git 仍会打印 `credential-manager-core` 警告，但 HTTPS push 成功。

## 结论

P0/P1 的远程体验主链路已基本完成并有实机证据。P2 的 SSH/DSRemote、完整插件 SDK、服务端删除属于独立工程，需要单独排期；不建议在未明确需求前继续扩张。
